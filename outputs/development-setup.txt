2. 대상 기기 구분
==========================================================================
이 환경은 "디스플레이가 있는 Rokid Glasses" 기준입니다.
  - 시스템: YodaOS-Sprite, Android 12 (API 31) / Android Go
  - 화면: 480 x 640, 단색(녹색)
  - 적용 문서: AIUI 문서, Bare-Metal Development 문서

적용하지 않은 문서
  - Rokid Air / Max / AR Lite / AR Studio 등 DP 입력형 AR 안경: UXR SDK·AXR SDK 계열.
    https://developerdoc.rokid.com/sdk 페이지는 이 계열(UXR/AXR SDK, DP 출력 필요)을 설명합니다.
  - 기업용 Glass3 계열 문서
  - CXR-M (휴대폰 쪽 SDK, Rokid 전용 Maven 저장소 필요): 이용 조건을 확인하지 못했으므로
    사용하지 않았습니다. 공식 샘플도 CXR 의존성 없이 표준 Android 저장소만 씁니다.

내 안경의 모델·펌웨어는 아직 확인하지 못했습니다. 확인 방법:
  - 휴대폰 Rokid AI(Hi Rokid) 앱 > 기기 탭 > 오른쪽 위 설정(톱니바퀴)
    안경 이름, 일련번호, 안경 시스템 버전(YODAOS-SPRITE 표기)이 보입니다.
  - ADB 연결 후에는 설치 작업이 제조사·모델·Android 버전을 먼저 출력합니다.

5. 안경 연결 (ADB)
==========================================================================
현재 상태 (2026-10-11)
  - adb devices -l : 연결된 기기 없음
  - Windows 장치 관리자에도 Rokid/ADB 장치가 없음 (마우스·웹캠 등만 보임)
  - 즉 드라이버나 승인 문제 이전에, 안경이 USB 데이터 장치로 잡히지 않는 단계입니다.
    동봉 충전 케이블로 데이터 연결이 되는지는 확인되지 않았습니다.

공식 문서의 요구 사항 (Bare-Metal Development Quick Start)
  - 소매 패키지에는 충전 케이블만 들어 있는 경우가 많고, 디버깅에는 전용 개발 케이블이 필요합니다.
  - 개발 케이블은 Rokid 개발자 포럼(https://forum.rokid.com) 또는 공식 개발자 지원을 통해 받습니다.
  - 휴대폰 Rokid AI 앱에서 안경 ADB를 켜야 합니다.

연결 순서
  1) 개발 케이블로 안경을 PC USB 포트에 직접 연결합니다.
  2) 휴대폰 Rokid AI(Hi Rokid) 앱 > 기기 탭 > 설정(톱니바퀴) > 개발자(Developer)
     > "안경 ADB 디버깅" 스위치를 켜고 경고창에서 확인합니다.
     (공식 스크린샷은 중국어판 기준: 设置 > 开发者 > 眼镜ADB调试 > 确认开启.
      글로벌판 Hi Rokid의 정확한 메뉴 이름은 직접 확인하지 못했습니다.)
  3) VS Code 작업 "기기: 연결 확인" 을 실행합니다.

상태별 조치
  device        정상. 설치·실행 가능.
  unauthorized  이 PC의 디버깅 키가 승인되지 않은 상태입니다. 사용자가 직접 해야 할 일:
                - 앱의 "안경 ADB 디버깅"이 켜져 있는지 확인
                - 안경 화면이나 휴대폰 앱에 USB 디버깅 허용 요청이 뜨면 허용
                - 요청이 안 보이면 케이블을 뽑았다 다시 꽂고 다시 확인
  offline       케이블을 다시 꽂고 안경을 깨운 뒤 다시 확인
  목록에 없음   케이블(데이터 지원 여부), USB 포트, 앱의 ADB 스위치 순으로 확인

기기가 여러 대일 때
  스크립트는 대상을 자동으로 고르지 않고 목록을 보여 준 뒤 멈춥니다. 다음 중 하나로 지정합니다.
  - 명령에 -Serial <serial> 추가
  - work\device-serial.txt 첫 줄에 serial 적기 (VS Code 작업은 이 파일을 사용)
  - 환경 변수 ANDROID_SERIAL
  설치 전에 기기의 제조사·모델·Android 버전을 출력하며, Rokid도 아니고 Android 12(API 31)도
  아니면 설치를 멈춥니다. 대상이 맞다면 -Force 로 계속할 수 있습니다.

연결 후 명령
  ... -File $s devices            연결 상태
  ... -File $s device-info        aix device (개발자 모드, 설치된 Agent 보기. 읽기 전용)
  ... -File $s install-launch     aix show > aix install > aix launch-page pages/index/index
  ... -File $s launch             페이지만 다시 열기
  ... -File $s logs               logcat (앱·AIUI 관련 줄만)
  ... -File $s logs -All          logcat 전체
  ... -File $s logs -Pattern "Speak English|chromium" -Save    필터 지정, work\logs 에 저장

  스크립트 없이 공식 명령 그대로 (work 폴더의 node, cli.js 경로 사용)
    adb devices -l
    node cli.js device
    node cli.js show    <앱 폴더>
    node cli.js install <앱 폴더> --serial <serial>
    node cli.js launch-page <앱 폴더> pages/index/index --serial <serial>

알아둘 점
  - aix launch-page 의 성공 메시지는 "실행 요청이 수락됨"일 뿐입니다. 화면과 음성 동작은
    안경에서 직접 확인해야 합니다 (공식 문서 명시).
  - 설치가 런타임 버전 불일치로 실패하면 app.json 의 engine(현재 >=0.18.0)을 조정합니다.
  - aix show / install / launch-page 를 폴더에 처음 실행하면 앱 폴더에 .aix\agent-id 가 생깁니다.
    이것은 로컬 개발 설치용 ID(develop.rokid.agent.<uuid>)로, Studio Agent ID와 별개입니다.
    지우면 안경에 새 Agent로 중복 설치될 수 있으니 유지하세요. AIX 패키지에는 포함되지 않습니다.
  - 로그 필터 기본값은 추정입니다. 실제 기기 로그를 본 뒤 -Pattern 으로 조정해야 합니다.
  - 기기 로그에는 다른 앱의 정보가 섞일 수 있습니다. -Save 로 저장한 파일은 공유 전에 확인하세요.

하지 않는 것
  초기화, 루팅, 펌웨어 교체, 무선 ADB(adb tcpip) 활성화는 스크립트에 없고 실행하지도 않았습니다.
  aix device set-dev(개발자 모드 켜기)도 실행하지 않습니다. Widget 디버깅 때만 필요합니다.

7. 실제 음성 테스트 경로
==========================================================================
가. Rokid / Hi Rokid 가 제공하는 서비스 (기존 승인 범위 안)

  1) 케이블 없이 안경에서 테스트 — 지금 바로 시도할 수 있는 경로
     - AIUI Studio(https://aiui-global.rokid.com)에서 Speak English 프로젝트를 최신 로컬 소스로
       갱신하고 Build & Review > AIX Packaging 실행
     - 휴대폰 Hi Rokid 앱 > Settings > Developer Options > AIUI > Update glasses resource
     - 안경에서 앱을 열어 한국어로 말해 봅니다.
     주의: Studio의 클라우드 패키지는 로컬 소스(현재 0.1.1)와 다를 수 있습니다.
           이번 작업에서 Studio는 건드리지 않았습니다. 마켓 심사 제출도 하지 않았습니다.

  2) 개발 케이블 + ADB: 5장의 install-launch. Studio를 거치지 않고 로컬 소스를 바로 올립니다.

  3) AIUI Studio / AIUI Editor 의 웹 시뮬레이터: 공식 문서는 웨이크업·음성 인식·LLM·음성 재생
     흐름을 시뮬레이션한다고 설명합니다. 한국어 인식이 되는지는 확인하지 못했습니다.

  한국어 지원 여부
     - AIUI 개발 문서에는 SpeechRecognition 지원 언어 목록이 없습니다.
     - 판매처 제품 설명에는 음성 상호작용 12개 언어에 한국어가 포함되어 있다고 나오지만,
       이것이 AIUI 앱의 ko-KR 인식을 보장하지는 않습니다.
     - 앱은 language-not-supported 오류를 별도 문구("한국어(ko-KR)를 지원하지 않습니다")로
       표시하므로, 안경에서 한 번 실행해 보면 판별됩니다.

나. 별도 음성 인식·번역 백엔드 — 결정이 필요합니다. 아무것도 가입·연결하지 않았습니다.

  방식 1) 앱에서 직접 연결
     마이크 녹음(getUserMedia + MediaRecorder) > 내 서버(HTTPS/WebSocket) > 음성 인식·번역 제공자
     - API 키는 서버에만 두고 앱 소스·AIX·로그에는 넣지 않습니다.
     - 필요한 것: 제공자 계정과 결제 수단, 서버를 올릴 곳, Studio 권한 설명 갱신
       (음성이 Rokid 외 제3자에게 전송된다는 점 명시)
     - 안경의 네트워크는 휴대폰 블루투스 링크를 거칠 수 있어 지연을 실기기에서 확인해야 합니다.

  방식 2) PC 미리보기 전용
     Ink 웹 런타임에는 hostCapabilities 로 음성·LLM 제공자를 꽂는 지점이 있습니다
     (런타임 코드에서 확인, 공식 문서에는 없음). 자체 미리보기 페이지를 만들면 PC에서 음성
     흐름을 돌려볼 수 있지만, 안경의 실제 동작을 대변하지 않고 런타임 갱신 시 깨질 수 있습니다.

  후보 제공자 (가격은 2차 출처 기준, 계약 전 공식 가격표 확인 필요)
     - OpenAI: 음성 인식 약 $0.003~0.006/분 + 번역용 모델 토큰 비용. 음성이 OpenAI로 전송됨.
     - Google Cloud: Speech-to-Text v2 약 $0.016/분 + Cloud Translation(가격 미확인).
       음성이 Google Cloud로 전송됨.
     - 국내 제공자(Naver CLOVA Speech / Papago 등): 가격 미확인.
     참고 규모: 10초 발화 100회는 약 17분이므로 테스트 비용은 1달러 미만 수준입니다.

  권장 순서
     먼저 가-1)로 Rokid 서비스의 한국어 인식 여부를 확인하고,
     미지원으로 확인될 때만 나)를 검토하는 것이 비용·개인정보 면에서 유리합니다.

8. Android 독립 앱 개발
==========================================================================
공식 요구 사항 (Bare-Metal Development 문서 + 공식 샘플의 빌드 파일에서 확인)
  안경 OS        YodaOS-Sprite, Android 12 (API 31) / Android Go
  minSdk 31 / targetSdk 36 / compileSdk 36.1
  Gradle 9.4.1 / Android Gradle Plugin 9.2.1 / Kotlin 2.2.10 / JDK 21 (소스 호환 Java 11)
  UI             Jetpack Compose, 480 x 640
  기능           표준 Android API (AudioRecord 8채널, CameraX, SensorManager, KeyEvent·브로드캐스트)
  저장소         google, mavenCentral (+ 샘플이 넣어 둔 aliyun google 미러). Rokid 전용 SDK 없음.

빌드
  VS Code 작업 "Android: 샘플 debug APK 빌드", 또는
  ... -File $s android-build
  결과: work\android-samples\GlassesBareDevSample\app\build\outputs\apk\debug\app-debug.apk

안경에 설치·실행 (개발 케이블 연결 후)
  ... -File $s android-install     adb install -r
  ... -File $s android-launch      샘플 앱 실행
  화면 미러링은 공식 문서가 scrcpy를 권합니다 (설치하지 않았습니다).

VS Code·명령줄로 가능한 것
  - Gradle 빌드, APK 설치·실행, logcat 확인
  - Kotlin 소스 편집 (Kotlin 확장을 설치하면 문법 강조 수준. 확장은 설치하지 않았습니다.)

Android Studio가 필요한 것 (공식 문서의 권장 IDE)
  - Compose 미리보기(@Preview), Layout Inspector
  - 중단점 디버깅, 프로파일러
  - 정확한 Kotlin·Compose 자동완성과 리팩터링, 새 프로젝트 마법사
  설치한다면 SDK 위치를 work\android\sdk, Gradle JDK를 work\android\jdk-21.0.12.1_1 로 지정하면
  이번에 받은 것을 그대로 재사용할 수 있습니다.

AIUI 앱과의 관계
  speak-english 는 AIUI 앱 그대로이며 Android 앱으로 변환하지 않았습니다.
  샘플은 별도 폴더에 원본 그대로 있습니다(수정 없음).
  독립 Android 앱에서는 AIUI의 SpeechRecognition / LanguageModel 을 쓸 수 없으므로,
  같은 기능을 만들려면 음성 인식·번역 백엔드를 직접 붙여야 합니다 (7장 나).
