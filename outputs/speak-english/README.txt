Speak Korean — 버전 0.4.0

기존 통합 앱의 이름을 Speak Korean(스피크 코리안)으로 바꿨습니다.
호출 문구는 "Hi Rokid, open Speak Korean" 또는 "스피크 코리안 열어 줘"입니다.
French와 같은 역할 구분으로 정리했습니다. 설명에는 기능만 적고, 앱 실행 지시는 Agent 프롬프트와 AGENTS.md에 둡니다. 시작 안내는 한국어로 제공합니다. 실제 호출 분기는 Rokid 호스트가 결정하므로 안경에서 확인해야 합니다.
폴더 outputs/speak-english, VS Code 작업공간과 기본 개발 명령은 그대로 사용합니다.
기존 Speak French는 호환용으로 남아 있지만 새 통합 앱에서 프랑스어도 선택할 수 있습니다.

사용 방법
1. 앱을 열면 한국어 메뉴에서 영어 / 중국어(간체) / 프랑스어 중 번역할 언어를 고릅니다.
2. 중국어와 중국어와 프랑스어는 한글 근사 발음을 함께 볼지 선택합니다. 번역만 선택하면 발음 생성도 요청하지 않습니다.
3. 버튼을 누르고 한국어로 말합니다. 다시 누르거나 문장이 확정되면 번역합니다.
중국어 발음은 표준 중국어를 한글로 옮긴 근사 표기이며, 한국식 한자 독음이나 병음이 아닙니다. 성조는 표시하지 않습니다.
입력은 ko-KR 고정입니다. 언어 자동 감지나 음성으로 메뉴를 제어하는 단계가 없습니다.

응답 지연 개선
- 녹음 버튼을 누르면 마이크를 먼저 시작하고 번역 세션 준비를 함께 진행합니다.
- 음성 인식이 확정되고 종료된 뒤에만 텍스트를 번역에 보냅니다.
- 번역문은 스트리밍으로 도착하는 대로 표시합니다. 수신 중 안내가 끝나야 완성된 결과입니다.
- 중국어와 프랑스어는 번역문부터 표시하고, 한글 발음은 응답 전체 검증 후 표시합니다.
- 스트리밍 API가 없는 구형 호스트에서는 한 번의 일반 요청으로 결과를 표시합니다.
- 취소·뒤로가기·오류·시간 초과 시 준비 세션, 스트림과 대기 타이머를 정리합니다.

조작
- 위/아래 밀기: 메뉴 선택 변경 또는 긴 결과 스크롤
- 확인/탭: 메뉴 확정, 음성 입력 시작·마치기, 번역 대기 중에는 취소
- 뒤로: 번역 대기를 포함한 모든 화면에서 기본 뒤로가기 동작을 허용합니다. 늦은 콜백을 무효화하고 작업 정리 전에 종료를 요청합니다. 화면 갱신이나 번역 응답을 기다리지 않습니다. 종료가 지연돼도 다음 뒤로가기를 막지 않습니다.
- 다른 언어를 고르려면 앱을 닫고 다시 엽니다.
- 대기·결과·오류·메뉴에서 60초 동안 조작하지 않으면 빈 화면으로 대기하며 앱은 유지합니다.
- 녹음·번역 중에는 화면을 지우지 않으며, 결과가 나온 시점부터 새로 1분을 셉니다.
- 빈 화면에서 탭은 다음 번역을 시작합니다. 아직 언어를 고르지 않았다면 메뉴부터 복원합니다.
- 음성 인식 20초, 인식 마무리 7초, 번역 25초 제한

개발 및 안경 반영
- outputs/development-setup.txt의 설치·사용 안내를 참고하세요.
- powershell -NoProfile -ExecutionPolicy Bypass -File outputs/scripts/rokid-dev.ps1 check
- 같은 명령의 check를 preview 또는 pack으로 바꾸어 미리보기/패키징합니다.
- AIUI Studio 기존 통합 Agent에 소스와 이름 Speak Korean을 반영하고 AIX Packaging 후 Save Details합니다.
- 휴대폰 Hi Rokid > Settings > Developer Options > AIUI > Update glasses resource 실행 후 다운로드 완료를 확인합니다.
- 안경에서 "Hi Rokid, open Speak Korean"로 실행을 요청합니다. 개인 테스트에는 Submit for Review나 개발 케이블이 필요하지 않습니다.

검증 범위
- 제어 로직 22개 + 타이머 5개 + 준비·스트리밍 16개 모의 검사, 구문·JSON·AIX 패키징 사전 검사를 통과했습니다.
- 이전 설명 수정 후 안경에서 앱 실행은 확인됐습니다. 새 중국어 발음, 번역 대기 중 뒤로가기, 번역 품질과 속도는 실기기 확인이 필요합니다.
- 로컬 미리보기에는 음성 호스트 기능이 연결되어 있지 않아 실제 음성 인식은 실패할 수 있습니다.
- 속도 개선 수치는 측정하지 않았습니다. 발음을 끄면 생성할 내용이 줄어들지만 서비스 응답 시간은 별도입니다.

음성 재생, 화자 식별, 상시 녹음, 원음·번역 기록 저장은 하지 않습니다.
기존 Rokid/Hi Rokid SpeechRecognition과 LanguageModel만 사용합니다. 외부 공급자나 API 키를 추가하지 않았습니다.

Studio 기본 정보
- Agent Name: Speak Korean
- Opening Message: 번역할 언어를 고른 다음 버튼을 누르고 한국어로 말하세요. 중국어와 프랑스어는 한글 근사 발음 표시 여부도 선택할 수 있습니다. 뒤로가기를 누르면 종료합니다.
- Feature Description: 버튼을 누르고 말한 한국어를 영어, 중국어 간체 또는 프랑스어로 번역합니다. 번역문과 인식한 한국어를 함께 표시하며, 중국어와 프랑스어는 한글 근사 발음을 선택할 수 있습니다. 한국어 메뉴를 버튼과 밀기로 조작합니다. 뒤로가기로 종료하고, 1분 동안 조작이 없으면 앱을 유지한 채 화면만 비웁니다. Rokid 음성 인식·번역 서비스를 사용하며 음성 재생과 기록 저장은 하지 않습니다.
